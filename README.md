# Java Fundamentals

This repository contains basic Java programs to practice fundamental programming concepts.  
Each program demonstrates a simple problem statement and its solution in Java.

## 📂 Programs Included

- **addtwonumbers.java** → Adds two numbers and prints the result.
- **areaofcircle.java** → Calculates the area of a circle given the radius.
- **averageofthreenumbers.java** → Finds the average of three numbers.
- **celciustofarenheit.java** → Converts temperature from Celsius to Fahrenheit.
- **kilometertomiles.java** → Converts distance from kilometers to miles.
- **perimeterofrectangle.java** → Calculates the perimeter of a rectangle.
- **powercalculation.java** → Calculates the power of a number (base ^ exponent).
- **simpleinterest.java** → Calculates Simple Interest using P, R, and T.
- **volumeofcylinder.java** → Calculates the volume of a cylinder.

## 🛠 Requirements

- Java JDK (8 or above)  
- Any Java IDE (IntelliJ, Eclipse, VS Code) or terminal with `javac`
